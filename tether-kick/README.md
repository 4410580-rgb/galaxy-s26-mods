# TetherKick

起動するだけの空アプリ（ON用・OFF用の2つ）。Galaxyの「モードとルーチン」の
「アプリを開いたとき」条件と組み合わせて、背面タップでテザリングを切り替える。

## 入手
GitHub の Releases から `TetherON.apk` と `TetherOFF.apk` をダウンロードしてインストール。

## 設定
1. モードとルーチン → ルーチンを2つ作成
   - 条件「アプリを開いたとき：テザON」→ アクション「モバイルホットスポット ON」
   - 条件「アプリを開いたとき：テザOFF」→ アクション「モバイルホットスポット OFF」
   - どちらも「ルーチン終了時に元に戻す」はオフ
2. Good Lock → RegiStar → 背面をタップ
   - 2回タップ → アプリを起動 → テザON
   - 3回タップ → アプリを起動 → テザOFF

## 調整
ルーチンが反応しない場合は `KickActivity.java` の `HOLD_MS` を増やす。
