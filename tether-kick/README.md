# テザリングON/OFF（tether-kick）

背面タップ1つでテザリングをトグルする。Galaxyの「モードとルーチン」と組み合わせて使う。

## 仕組み
1. 背面タップ →「テザリングON/OFF」（本体）が起動
2. 本体が現在のテザリング状態を判定し、OFFなら「テザリング補助ON」、ONなら「テザリング補助OFF」を開いて即終了
3. 補助アプリは透明・1px・タッチ素通しで2秒だけ前面に留まり、ルーチンに検知させる
4. ルーチンがテザリングをON/OFFする

ルーチンはテザリング状態を条件にしないので、ON→OFFの往復が起きない。

## 入手
Releases から最新の3つをインストール。固定鍵で署名しているので次回以降は上書きできる。
- `TetherToggle.apk`（本体）
- `TetherHelperON.apk` / `TetherHelperOFF.apk`（補助）

補助アプリ2つはホーム画面設定の「アプリを非表示」でドロワーから隠してよい。

## ルーチン設定
| ルーチン | 条件 | 実行内容 |
|---|---|---|
| テザリングon | アプリ起動時：テザリング補助ON | Wi-Fiテザリング ON |
| テザリングoff | アプリ起動時：テザリング補助OFF | Wi-Fiテザリング OFF |

RegiStar → 背面をタップ → 2回タップ → アプリを起動 → テザリングON/OFF

## 調整
- 反応しない → `HoldActivity.java` の `HOLD_MS` を増やす
- 「状態を判定できませんでした」と出る → `ToggleActivity.java` の判定処理を見直す
