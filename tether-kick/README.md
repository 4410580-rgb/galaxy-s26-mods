# テザリングON/OFF（tether-kick）

起動するだけの空アプリ。Galaxyの「モードとルーチン」と組み合わせて、
背面タップ1つでテザリングをトグルする。ON/OFFの判定はルーチン側で行う。

## 入手
Releases から最新の `TetherToggle.apk` をダウンロードしてインストール。
固定鍵で署名しているので、次回以降は上書きインストールできる。

## ルーチン設定
| ルーチン | 条件（すべて満たすとき） | 実行内容 |
|---|---|---|
| テザリングon | Wi-Fiテザリング OFF ＋ アプリ起動時：テザリングON/OFF | Wi-Fiテザリング ON |
| テザリングoff | Wi-Fiテザリング ON ＋ アプリ起動時：テザリングON/OFF | Wi-Fiテザリング OFF |

RegiStar → 背面をタップ → 2回タップ → アプリを起動 → テザリングON/OFF

## 調整
- 反応しない → `KickActivity.java` の `HOLD_MS` を増やす
- ONにした直後にOFFへ戻る（往復する）→ `HOLD_MS` を減らす
